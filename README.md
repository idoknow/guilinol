# Guilin Online · 网上桂林

真实地理布局的桂林第三人称 3D 城市漫游，目标地址 https://glol.rcpd.cc 。

- 方案：three.js + 离线数据预处理 + 256 m 分块流式加载，桌面和手机都能玩。
- 交接文档：`docs/handoff-roc14.md`（调研、数据摸底、初版计划）。
- 原始数据（OSM / Overture / Terrarium DEM）不入库，放 `raw/`，获取方法见交接文档第 8 节。
