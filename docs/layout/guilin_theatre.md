## 桂林剧院（漓江歌剧院）多源证据底图与布局核对

本底图对应 IDOK-70（M2.6-25），覆盖桂林市文化旅游中心核心建筑**桂林剧院（漓江歌剧院）**及其南侧“花蕾”音乐厅、流线型退台裙楼、北侧迎宾广场与生态停车场、东侧临江路背面界面、跨街连廊及西侧滨水保留建筑。所有几何坐标统一转换至项目 WGS84 基准（`LON0 = 110.300, LAT0 = 25.280`），地标局部坐标原点 `(0, 0)` 对齐 OSM `way/1466385147` 几何形心 `110.2990054, 25.2775606`（世界 `(-100.12, 269.73)`，最终世界地形采样锚点标高 `154.45 m`）。配套矢量要素见 `docs/layout/guilin_theatre.geojson`。

### 坐标转换方法与已知控制点校验（沿用 IDOK-50 / IDOK-51）

1. **基准图层**：以 OSM（2026-11 快照）与 Esri World Imagery（`identify` 元数据：传感器 `WV03` / Vantor Vivid Advanced，拍摄日期 `2024-12-24`，地面采样分辨率 `0.31 m`，图层源精度字段 `8.47 m`）为几何基准，直接使用原始 WGS84 坐标，不重复偏移。
2. **百度 BD09MC / 高德 GCJ-02 转换链**：
   - 百度检索返回的 `diPointX / 100`、`diPointY / 100` 为 BD09MC 米制墨卡托坐标，先按百度六带逆投影多项式还原为 BD-09 经纬度；
   - 以 BD-09 → GCJ-02 极坐标反算为初值，迭代 6 次消除正算残差得到 GCJ-02 坐标；再以 6 次不动点迭代反解克拉索夫斯基椭球非线性偏移得未配准 WGS84；
   - 最后叠加 IDOK-50 / IDOK-51 梯度互相关（NCC）影像配准修正量 `Δlon = −0.0000397°`、`Δlat = −0.0000314°`（约西移 `4.0 m`、南移 `3.5 m`）。
3. **已知点残差校验（阈值 `< 5 m`）**：
   - 隔江对岸已知控制点 **逍遥楼**（OSM `way/702352884` 主楼形心 `110.2972532, 25.2813084`，场景 `(-276.49, -144.67)`）：百度主 POI `ea6e803724ead9d54f2fdf7b`（`diPointX=1227960141, diPointY=289232343`）经上述转换后为 `110.2972452, 25.2812340`（场景 `(-277.29, -136.45)`），落在逍遥楼台基轮廓内，东西向偏差仅 **`0.80 m`**（距主楼北檐口 `< 0.8 m`），以及 IDOK-50 复核正阳门（`way/1008248059`）、承运门（`way/1008248065`）、十字街三处影像配准残差 `0.0 m / 0.0 m / 0.7 m`，均满足 `< 5 m` 校验要求。
   - **漓江歌剧院主 POI**（百度 UID `9b6675800a3a7f45734b8775`，`diPointX=1227977845, diPointY=289188186`）：转换后为 `110.2988246, 25.2776496`（场景 `(-118.31, 259.89)`，相对 `way/1466385147` 锚点局部 `(-18.19, -9.84)`），准确落在 `way/1466385147` 歌剧厅主轮廓内。

### 建筑体块、屋顶形态与周边场地要素核对表

主歌剧厅采用平行/垂直于东侧临江路（`way/682893309`，走向约 `26° / 206°`）的**正交十字四瓣“盛开桂花”单层网壳**（四边内凹圆角方形外轮廓），中心小圆锥与采光点位于地标局部 `(+2.5, -2.5)`（中心低：`+21.8 m`，锥尖 `+23.4 m`）；四片饱满圆润的纯白光滑椭圆花瓣沿 `NE (26°)`、`SE (116°)`、`SW (206°)`、`NW (296°)` 严格 `90°` 正交向外上方伸展上翘至全屋顶最高点（尖端标高：`NW +31.8 m`、`SE +29.5 m`、`NE +28.0 m`、`SW +27.6 m`），每片上翘花瓣尖端下方自然张开高耸的抛物线深灰蓝通高玻璃大拱口（“眼睛”）并由 8 根白色斜向巨柱夹持；相邻花瓣之间为四片向下深凹垂至裙楼顶（`+10.8 m`）的**蓝灰底细白菱形网格玻璃鞍谷**（白肋仅布置于椭圆花瓣边缘与外缘拱圈）；主厅南侧紧邻一座椭圆形平面的**“花蕾”音乐厅**（891 座），外围由 2–3 层带喀斯特远山穿孔图案的白色流线型退台裙楼整体包绕。

### 拆迁旧建筑清理核对（Overture 历史残留）

2024-12-24 Esri 影像显示临江路（`way/682893309`）以西、漓江东岸及訾洲河汊道（`way/221349741`）以北的剧院红线内，2018 年新生街棚改前的村屋已全部拆除并建成歌剧院裙楼、南侧音乐厅及园林绿地。除原已登记的 7 个 Overture ID 外，将位于音乐厅及西/南裙楼正下方的 8 个拆迁残留框（`dca8a316`、`cd140513`、`dd96fd6f`、`4c643ed2`、`b5404ca8`、`60812549`、`ef8cdbdc`、`9db5c8f7`）一并纳入 `landmarks.json` 的 `replace` 列表；临江路以东新建成的兴进·繁花里建筑群（`8a5294aa`、`f31e9d3d` 等）完整保留。
