## 看到了什么（和现在的差距）

### 植被：城市是“埋在树里”的（R2、R4、R8、R11、R12）
- 从高处看，城区一半以上的地面被树冠盖住：街道两侧、河湖两岸、单位大院里都是连成片的**深绿阔叶树冠**，楼顶从树冠里冒出来。现在画面里一棵树都没有，这是差距最大的一项。
- 树种印象：香樟、小叶榕/黄葛榕（湖边大榕树，冠幅 15–25 m、气根，R4）、桂花（小乔木）、滨江路成排**棕榈/大王椰**（R11、R13）、日月双塔背后的**水杉/柏树**尖塔形（R8）。
- 颜色明显比现在山体的“石绿”更深更饱和：近处树冠 `#2f5a2c`–`#4c7a3a`，受光面偏黄绿 `#6f9445`，背光近黑绿 `#1f3a22`。

### 山体：绿植包裹，裸岩只在陡壁（R3、R7、R14、R16）
- 孤峰顶部和缓处全被灌木乔木盖住，**颜色是深绿而非石青**；裸露岩壁是**灰白带竖向黑褐水痕**（`#b8b6ad` 底、`#5e5a52` 水痕），偶有赭黄锈斑。
- 近水的崖脚有被水蚀的凹槽和乱石（R3、R7）。
- 远处层叠的峰由深绿变成灰蓝，越远越淡（R6、R15），这一点 M1 的大气透视已经对上。

### 建筑：白瓷砖多层楼 + 老城灰瓦 + 少量绿琉璃（R2、R6、R9、R12、R16）
- 主体是 4–8 层的**白/米白瓷砖面**混凝土楼，平屋顶上有楼梯间、水箱、太阳能，窗是横向条窗、阳台密集。
- 老城片区（东西巷、王城周边）是**灰瓦坡屋顶**，屋脊直，两头微翘，墙面白灰或青砖（R12）。
- 机关、学校、宾馆常见**绿色琉璃瓦歇山顶**（R2 中部一片）——这是桂林城区很有辨识度的一笔。
- 王城、庙宇：黄/朱红墙、红柱、灰瓦（R16）。
- 首层多是商铺：雨棚、招牌一排，颜色比楼身花（R9）。远看只需要首层一条深色带 + 零星彩色招牌色块。

### 街道与岸线（R2、R10、R11）
- 主街：浅灰花岗岩铺地人行道，花箱，**装饰灯杆**（顶部多头灯），行道树间距约 6–8 m。
- 河湖岸：**石砌直立驳岸**，顶上白色/浅灰石栏杆，岸边步道 + 一排大树（R2 桃花江段最典型）。
- 桥：石拱桥（R2、R11），桥身浅灰石、拱圈明显。

### 光与水（R1、R4、R5、R13、R14，留给 M3）
- 水面是**暗绿玉色**，倒影很强，夜晚满是暖色灯光倒影。
- 夜景：岩壁被绿/暖黄泛光照亮，双塔金色和银白色，亭廊暖黄灯（R1、R4、R5、R14）。
- 黄昏：峰林剪影 + 粉橙天空（R13）。

## 对 M2.5 的目标
1. **树是第一优先**：街道两侧行道树、河湖两岸大树带、公园和林地成片、单位大院零散点种。高处俯视时树冠覆盖率要达到“楼从树里冒出来”的程度。
2. 山体着色改成**深绿植被为主、陡壁灰白带水痕**，石青只留给远处的大气透视。
3. 建筑分三类：白瓷砖平顶多层（主体，带屋顶杂物和条窗）、灰瓦坡顶（老城）、绿琉璃歇山顶（OSM `school`/`university`/`college`/`hospital`/政府类里挑一部分）。
4. 河湖岸加石砌驳岸 + 栏杆 + 岸边树带；主街加装饰灯杆和花箱。
