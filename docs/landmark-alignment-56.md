## 成品几何与底图

`npm run audit:landmarks -- --strict` 读成品 GLB、GL04 和独立的 OSM/Overture 快照，不读生成器的位置作为实测结果。`uv run python pipeline/landmark_overlay.py` 输出八张斜投影叠图。图例中灰线是 OSM 路网，蓝色是独立 GLB；不放校牌的学校没有蓝色模型。

|对象|核对方法与结论|
|---|---|
|状元廊|`way/1531321916` 是 42 × 4 m 的长廊屋顶。原先在 2 m 处量到柱子和旁边住宅；改为量可见屋盖的水平投影，IoU 0.973。|
|逍遥楼|`way/702352884` 对应楼座，不是 34 × 48 m 的整座城台。在城台顶（8.4 m）与楼座顶（9.84 m）之间截取楼座。近方形轮廓比较两组正交边线，IoU 0.919，边线差 2.28°。|
|靖江王城|以 OSM 轮廓的中心及长轴放置承运门（含侧翼）；正阳门测城楼顶部，承运殿测台基，东西配楼测分块内按建筑标识拼合的碰撞轮廓。五项 IoU 0.764–1.000。|

## 照片位置复核

“中心命中”仅指原 EXIF 水平中心射线与地图几何相交，不等于门廊居中或视野无遮挡。没有独立地图参照的小物件不凭照片反推坐标。

|1295 / 1299 / 1303|学校只对照临街外观，不拟合入口。1303 中的招牌不能仅凭同一条街上有民宿就关联到某栋建筑。|
|1304–1305 / 1310–1316|古南门城台相对 `way/521248472` 的中心差 0.28 m、角差 0.12°。1305 中心命中；1313 的原朝向连地图轮廓都不在视野中，1314–1316 在视野边缘。该快照没有独立的大古榕树干/树池测点，不移动城台去补树的位置。|

## 解放桥冷加载

西桥头跨滨江路的上层桥板由 `jiefang_bridge.glb` 提供；分块故意省略该处重复的程序桥面，让下层道路可穿行。只等地形块、不等桥体时，步行会落到下层道路，再被滨水边界拦住。在相同地形、相同王城模型下单独移除解放桥碰撞即可复现 `(−250.03, 18.86)`、脚底 `143.78 m`，不是王城 flatten 延伸到了江岸。现在西桥头出生在获取地形后优先加载桥体，失败时不放置角色。快速回归以冷桥资源开始，并检查脚确实在桥面上，而不仅是下方有水。
