## 二、1:1 建模与涂装提取规格

### 1. 门口招聘立牌 (`drinks/props/recruit-sign.ts`)
- **支架形态**：参考 `recruit_photo_08.jpg`，采用深炭黑金属扁方管门型 / A 字落地架（前后斜撑夹角约 ±8°，底端四枚橡胶防滑脚垫贴地 `y = 0`），整体宽 `0.58 m` × 高 `1.22 m` × 展开进深 `0.42 m`，摆放在正门左外侧（不挡 2.4m 宽正门通行区）。
- **主色色板**：
  - 蜜雪红主题框与顶部：`#E60012` / `#D9252E`
  - 高对比纯白信息卡与文字：`#FFFFFF`
  - 点缀金黄/暖橙（冰淇淋蛋筒与徽章点缀）：`#FFD800` / `#F5A623`
  - 深炭黑正文与边框阴影：`#141414`
- **版面结构（自上而下）**：
  1. 顶部红色圆角门头徽章（雪王三齿白皇冠剪影 + 红披风）与粗体白色「蜜雪冰城」
  2. 超大白底红字/红底白字主标「招聘 · 加入我们」
  3. 居中白色高对比卡片，分栏列明岗位（`调饮师 · 收银员 · 储备店员`）、待遇与排班
  4. 底部红色收口提示条与近距离微光描边反馈

### 2. 员工服 (`drinks/staff/uniform.ts`)
- **上衣**：纯黑工作短袖/工装马甲轮廓（`#141414`），左胸印雪王皇冠小徽章 + 红白袖口铭牌。
- **围裙**：经典黑底防水围裙（`#181A1E` 配蜜雪红 `#E60012` 挂脖带与腰际滚边），胸前正中居中印白色「蜜雪冰城 · 店员」铭牌标，腰部配分隔前插袋（还原奶茶店实用围裙切工）。
- **帽子**：纯黑弯檐棒球帽（`#141414`），帽冠正面正中绣白色皇冠萌偶徽章，纯黑帽檐干净利落（不做多余花哨滚边）。
