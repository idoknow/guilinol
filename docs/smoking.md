# 香烟 / 打火机

联机、单机都能抽。每个人背包里固定 20 包烟，每包 20 根；快捷栏 6 格对应键盘 1–6。

## 操作

| 场景 | 端游 | 手游 |
| --- | --- | --- |
| 用快捷栏第 N 格 | 按 `1`–`6` | 点底部快捷栏格子 |
| 打开 / 关闭背包 | `TAB` | 点右下「香烟背包」按钮 |
| 把烟放进快捷栏 | 从背包拖到格子 | 点一下香烟，再点格子 |
| 换回背包 / 换格子 | 拖回背包区，或在格子之间拖 | 先把格子里的选中，再点目标格子 |

第一次按某个格子 = 取烟 + 点烟（左手举烟盒、右手拿打火机擦火），大约 1.45 秒后点着。
已经点着之后再按**同一格** = 吸一口。

两个细节：

- **烟是点着了才从包里扣掉的。** 取烟/点烟那 1.45 秒里改主意换别的格子，不会白烧一根烟。
- **左手举着的烟盒在点着之后会收回去。** 之后只有右手夹着烟，左手回到正常走路摆动 —— 否则你会举着烟盒走三分钟。

## 一支烟怎么烧

| 规则 | 数值 | 实现在哪 |
| --- | --- | --- |
| 一整根的可燃时间 | 180 秒（`BURN_TOTAL`） | `web/src/smoke/data.ts` |
| 没人吸时的消耗 | 1 秒 1 秒，烟头冒小烟 | `SmokeSession.advance` |
| 吸一口 | 立刻扣 30 秒（`PUFF_COST`），烟身短一截，烟头喷一大股烟 | `SmokeSession.puff` |
| 烧到 0 | 烟头掉在脚下地上，两分钟后消失 | `SmokeKit.dropStub` |

所以：**一直不吸，正好 3 分钟烧完；一口不落地吸，6 口就没了。**

这几条数字有回归测试：`npm run test:smoke`（`scripts/smoke-test.mjs`，只测纯逻辑，不需要浏览器）。

## 文件

| 文件 | 干什么 |
| --- | --- |
| `web/src/smoke/data.ts` | 品牌表、背包 / 快捷栏数据、存档（`glol.smoke.v1`）、燃烧常数。纯逻辑，不碰 three.js |
| `web/src/smoke/session.ts` | 一支烟的状态机（取烟 → 点烟 → 抽）与「别人那支烟」的网络整流。纯逻辑 |
| `web/src/smoke/anchors.ts` | 手 / 嘴的固定位置（角色空间，米） |
| `web/src/smoke/models.ts` | 程序化建模：烟盒、香烟、打火机、烟蒂、第一人称假手、烟雾粒子 |
| `web/src/smoke/kit.ts` | 把道具挂到手上 / 嘴边，并按 `SmokeView` 摆姿势 |
| `web/src/smoke/ui.ts` + `smoke.css` | 快捷栏、背包面板、拖放 |
| `web/src/smoke/index.ts` | 总装：背包 ↔ 状态机 ↔ 三维道具 ↔ 联机上报 |

接入点在 `web/src/walk/index.ts` 的 `frame()`：

```ts
function frame(dt: number) {
  smoking.advance(dt)   // 状态机先走，姿势才知道这一帧抬不抬手
  tick(dt)             // 物理 + character.pose({..., smoke: smoking.pose()}) + follow()
  smoking.place(dt)    // 相机定了再摆道具、冒烟
}
```

## 美术

四个品牌（南溪 / 漓江 / 桂花 / 象山）全部原创，不撞任何真实商标（和 `web/src/game/catalog.ts`
同一套规矩）。烟盒包装是用 `<canvas>` 现画的，所以不需要任何二进制素材。

尺寸按真实毫米换算：香烟 Ø7.9 × 84.5 mm、过滤嘴 25 mm；软包烟盒 58 × 89 × 23 mm；
一次性打火机 24.5 × 48 × 11.8 mm。

要把 `Downloads/xiangyan/南.max` 那套模型换成正式资产：在 3ds Max 里导出成 glb，
把 `web/src/smoke/models.ts` 里 `createPack()` 的函数体换成加载那个 glb 即可——它对外的接口
只有 `{group, lid, peek, parts}` 四个字段（`lid` 是绕 X 轴正转打开的盖子节点，`peek` 是取烟时
从盒口探出来的那一截）。浏览器加载不了 `.max` / `.psd`，所以现在这套是按原件的比例和版式重建的。

## 第一人称

走路默认是第一人称，眼位离胸口只有 0.25 m 左右，正常视角里根本看不到手。所以抽烟时另开一套
「视角模型」（viewmodel）：`viewRoot` 每帧复制相机的位置和朝向，里面放烟盒 / 打火机 / 香烟和两只
简化的手，位置写在 `VIEW_ANCHORS`（相机空间）。烟盒收回去时左手会沿 `restL` 落到画面外。
这一整套挂在 **layer 2** 上，水面镜像（只画 layer 0）就不会把自己照进漓江里。第三人称时才画
挂在人物身上的那一套。

## 联机

不额外开消息，直接把四个整数塞进已有的 `pos` 包：`sc`（0/1/2）、`sb`（剩余可燃时间 ×10）、
`sp`（吸了几口的计数）、`br`（品牌序号）。别人收到后重建一份 `RemoteSmoke`，用同一套
`SmokeKit` + `figure.pose` 渲染，所以对面看到的动作和你自己看到的是同一套。

细节见 `deploy/realtime/README.md` 的「抽烟字段」。
