# 抽烟玩法（香烟 2.0）

## 入口与持有

- **物品栏第 3 格「香烟」**：步行时按 `3` 或点击底部物品栏第 3 格取出；第 3 格角标显示持有包数（最多 3 包，每包 20 根），右侧「香烟铺」按钮购买 12 个虚构品牌（¥8–¥50，`lib/smoke.ts`）。
- **独立背包（`/backpack.html`）**：登录后同步云端存档（`/api/me/save` → `player_saves`），未登录读取本地 `glol.save.v1`。有烟时显示首包 `剩余 N / 20`（超过 1 包附 `· 共 M 盒`）与「按 3 或物品栏第 3 格拿出」，点击回游戏并写入一次性 `sessionStorage` 意图（进入步行时自动消费）；`packs` 为空时显示「已抽完」，点击回游戏并弹出香烟铺（`openSmokeShop('没有香烟了，去旁边的香烟铺买')`）。
- **持烟 HUD（`web/src/smoke/meter.ts`）**：手里有烟（`take` / `ready` / `light` / `smoking`，即 `view.cig > 0`）时，在物品栏上方居中显示宽度 `<= 160px` 的山水印小面板：顶部 `4px` 圆角进度条实时绑定 `burn / total`（自然燃烧连续减少，吸一口立刻扣 1 或 2 节；剩 `<= 2` 节时由青玉色转为淡朱色），下方一行小字显示 `剩余 N / 20`（多包加 `· 共 M 盒` / `· 另 M 盒`）。不拿烟时不渲染。

## 操作与数值

- 按 `interact` 键（默认 `F`，可改绑；触屏为 `.smoke-hint` 按钮）分阶段推进：
  - 未拆包（`opened=false`）：掏盒 → 拇指推盖 → 撕开封纸（`sealed`）→ 拿取香烟（`open`，调用 `takeFromPack` 扣 1 根；第 20 根拿完移出该包）→ 点燃（`ready`）→ 吸一口（`smoking`）。
  - 已拆包（`opened=true` 或 `remaining<20`）：掏盒推盖后跳过封纸直接拿取。
- 持烟期间再按 `3` 或点第 3 格「丢弃」可扔下烟蒂（不重复扣盒）；`Esc`、切槽、上车、倒地或执勤时自动收起。
- 每支烟在 `[150, 180]` 秒间随机（`rules.minSeconds`..`maxSeconds`，支持后台 `/api/smoke` 配置），分为 10 节：每吸一口消耗 1 节（`puffSegments=1`），有 20% 概率（`doubleChance=0.2`）一次消耗 2 节。

## 联机与测试

- `pos` 的 `sc` / `sb` / `sp` / `br` / `ss` / `sd` / `sr` 同步远端动作与烟身比例，不额外同步或展示他人的剩余根数。
- `?smoke=0` 下隐藏物品栏入口、背包香烟条目、HUD 进度条面板，并关闭远端道具与烟雾渲染。
- `npm run test:smoke` 验证状态机、扣减与移出规则、单/双节吸口比例、HUD 计数与低量阈值；`node scripts/verify-smoke-flow.mjs` 验证完整端到端流程与截图。
