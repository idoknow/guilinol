登录后在独立背包中点击「香烟」，同一标签页返回游戏。成功进入步行时消费一次 `sessionStorage` 意图；刷新不会重复取烟。没有快捷栏、品牌、包数或 HUD 按钮。

取烟结束后按「使用手中物品」（默认 Y，可改绑）点火；点着后同键吸一口。Esc、上车或离开步行可收起。一支自然燃烧 180 秒，每口减少 15 秒，间隔至少 15 秒。自然烧完掉下烟蒂，两分钟后移除。

`pos` 的 `sc` 表示无 / 准备点火 / 已点着，`sb` 是剩余秒数 × 10，`sp` 是吸气序号，`br=0` 是无品牌外观。宣传渲染统一传 `smoke=0`，不取烟、不渲染远端道具或烟雾。`npm run test:smoke` 验证状态机与单次意图。
