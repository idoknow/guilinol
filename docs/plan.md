# 第一期计划（2026-11-18 Rock 确认）

## 已定

- **范围**：先做市中心。核心框 `25.262–25.302 N, 110.278–110.312 E`（约 3.4 × 4.4 km）：北到叠彩山，南到象鼻山、穿山西侧，西到桂湖、老人山，东过漓江到七星公园。管线按 bbox 参数化，后面可以直接扩到全图。
- **风格**：见 `docs/style.md`。不参考南宁站，主打山水。
- **玩法**：风景观光向。走、骑、坐船看山水，找观景点，拍照。战斗、经济、任务链都不做。
- **技术**：three.js（WebGL2）+ Vite + TypeScript；离线 Python 管线；256 m 分块流式加载；Rapier（wasm）做碰撞；meshopt 压几何，KTX2 压贴图。
- **仓库**：`idoknow/guilinol`，私有。**部署**：Cloudflare Pages，`glol.rcpd.cc`。
- **性能底线**：中端安卓手机稳定 30 帧，桌面 60 帧，首屏 2 秒内能动。
