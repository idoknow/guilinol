# 广西师范大学育才校区建筑参考

127 栋中，14 栋有可匹配的外观照片，79 栋只有航拍依据，34 栋缺少可用外观证据。原始 OSM 的 40 栋具名建筑，扣除 13 栋编号宿舍和 2 栋附属外国语学校，余 25 栋，其中 9 栋有立面照片（36%，目标 20 栋）。指定的 16 栋重点建筑取得 3 栋地面照。IDOK-167 第二版附件含 45 张 JPEG，与目录逐项对应。

## 建模时如何使用

- 图书馆可对照校方基建处入口照片、校方斜俯视图和屋顶正射图。第二文科综合楼可对照入口玻璃、挑空门厅和楼前雕像。田家炳楼有不同时期的入口图；纪念馆有三个地面视角。
- 东苑餐厅和体育馆只有正射屋顶图。西苑食堂也只保留屋顶图。五、七舍的墙色和层数沿用六舍样式，详见下表。
- colors 为对应影像中的近似色。航拍屋顶色取自轮廓向内收缩后的像素中位数，受日照、阴影和影像年代影响。floors 配合 floors_src 和 floors_note 区分照片估读和同型推定，floors_min 为只看得到部分楼层或校方文字只能证明的下限。
- date 表示拍摄日期，无法核实则留空。各条 photos 给出原图、所在网页和视角，同一张全景的不同局部共享原图 URL。国际教育交流中心采用带楼名的学院照片，新国教楼为另一栋，未收入附件。南门历史图沿用作者标注；未经定位的点位坐标为空。

## 清单口径

使用[项目原始快照](https://github.com/idoknow/guilinol/releases/tag/raw-expanded-20261121)。以外环面积质心落入 way/643029633 为条件，得到 93 个 OSM building way 和 127 条 Overture 记录。93 对外环顶点集合完全相同，保留 OSM way 为 source，另存 overture_id。其余 34 条使用 Overture UUID。OSM 未提供 building:levels，Overture 未提供 num_floors 或 roof_shape。两栋原本无名的轮廓据校图、运动场和邻楼的位置关系补记为图书馆和体育馆。
