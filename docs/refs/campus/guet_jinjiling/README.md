## 金鸡岭校区资料底表

采用 [项目原始数据快照](https://github.com/idoknow/guilinol/releases/tag/raw-expanded-20261121) 的 OSM 校界 `way/606121236`，按建筑外环面积质心落在校界内筛选。OSM 快照提供建筑 way、名称和已标注层数。Overture 表提供 UUID、轮廓和已有属性。

共收录 66 个 OSM way 和 72 个 Overture UUID。其中 66 个 UUID 与 OSM 轮廓顶点集合一致，列入相应记录的 `overture_ids`，共 72 条记录。几何有差异的记录保留各自来源，尚待核对是否同楼。

## 照片与定位

[招生代理网站校园风光图集](https://www.guetgjbk.com/pic/) 为照片标注了校区；分别采用金鸡岭校门、图书馆、室内训练馆与校园全景四张原图。检索词包括“金鸡岭校区 东区图书馆”“桂电 九教 教学楼”“金鸡岭 主楼”。[学校图书馆通知](https://www.guet.edu.cn/lib/2026/1026/c4614a161518/page.htm) 单列金鸡岭馆和花江馆。

图书馆入口的中英文馆名、馆前草坪花园和临街教学楼群提供了航拍对照点。以图书馆南侧到金鸡路的顺序，四排教学楼对应七教至十教；四个局部裁自同一张航拍，均标为 aerial。体育馆以入口题字和 OSM 体育场地内的 Overture 轮廓定位。颜色为照片估色，拍摄日期及独立“主楼”所指未核实。附件保留全景以供复核。
