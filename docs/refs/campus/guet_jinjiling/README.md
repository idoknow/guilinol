## 金鸡岭校区资料底表

采用 [项目原始数据快照](https://github.com/idoknow/guilinol/releases/tag/raw-expanded-20261121) 的 OSM 校界 `way/606121236`，按建筑外环面积质心落在校界内筛选。OSM 快照提供建筑 way、名称和已标注层数。Overture 表提供 UUID、轮廓和已有属性。

共收录 66 个 OSM way 和 72 个 Overture UUID。其中 66 个 UUID 与 OSM 轮廓顶点集合一致，列入相应记录的 `overture_ids`，共 72 条记录。几何有差异的记录保留各自来源，尚待核对是否同楼。

## 建模参考

72 条记录中有 62 栋具名，其中 51 栋有地面实拍（82.3%）。仅计快照中 OSM 已命名的 61 栋时为 50/61（82.0%）。附件中的七教至十教各有地面视角，航拍裁图保留作楼列定位。校医院、二教、三教、三个食堂、正平科技文化馆、冠群楼、后勤楼均有立面图。层数按可见窗排、楼板、外廊和架空层计读，各楼的 `floor_count_note` 说明读数范围；高厅翼、遮挡部分和敞开屋顶可能影响估读。

本项目把第十教学楼（勤正楼，`way/621423420`）作为“主楼”的建模对象。楼端可读出“勤正楼”，金鸡岭校区的行政服务在此办公，学校也曾在楼内集中办理研究生报到。“主楼”是本项目对此地标的选取，图上沿用实际楼名。[学校财务处机构设置](https://www.guet.edu.cn/caiwuchu/633/list.htm) · [研究生入学须知](https://m.kaoyan.com/yanzhao/guet/luqu/14/484933/)

## 图源及辨认依据

- 按“桂林电子科技大学 金鸡岭校区＋楼名/宿舍号”检索百度地图。地点图核对楼牌；街景视角结合拍摄位置、朝向、遮挡和 OSM 轮廓辨认。每张照片的原图链接、视图链接和可查的拍摄月份在 catalog 中。编号楼按各自能看到的轮廓收图，沿用快照楼号；门牌不清的照片在 `view` 注明了定位方式。
- 招生代理网站的图集分列两校区图书馆，提供校门、体育馆、东区图书馆、教学区全景和七八教庭院。圆形楼梯塔、连廊和两翼窗间墙与地面街景对应。[校园风光](https://www.guetgjbk.com/pic/)
- 按“东区食堂”“生乐餐厅”找到校友报道。第一食堂对照生乐餐厅门头、半圆雨棚、双侧楼梯及地图餐饮地点。第二食堂对照藤蔓端墙与白砖柱廊。角度相近的转载不另算一次拍摄。[校友报道配图 20、21](https://www.sohu.com/a/376883087_120509469)
- 搜索各学院新闻、校园 vlog、百度百科、知乎和小红书的宿舍图。检出的花江宿舍区、未标楼号的室内图和平台通用封面均未计入覆盖。医院本部的校区归属另据学校说明。[校医院介绍](https://www.guet.edu.cn/hospital/2023/0112/c1641a23584/page.htm)
