### 花江图书馆实拍

以“桂林电子科技大学 校园风光 花江 图书馆”检索，招生代理机构的图集分别标注了花江与金鸡岭两馆。花江照片从湖对岸拍摄，可辨认弧形轮廓与水平窗带；树木遮挡底层，无法据此数清层数。图集没有给出拍摄时间。[校园风光图集](https://www.guetgjbk.com/pic/)

以“桂林电子科技大学花江校区图书馆”检索百度地图，在地点相册中按弧形外墙、窗格和馆名辨认出外墙平视及馆名近景两张照片。相册混有桂林市区景点，已排除；学校本科教学评估报道的五张配图都是室内场景。临湖面底层有遮挡，近处图中的水平窗框也无法直接换算为楼板数。[百度地图地点相册](https://map.baidu.com/poi/8bd3ab189d3eb5a7f423106d) · [学校教学评估报道](https://www.guet.edu.cn/2023/1113/c478a112008/page.htm)

## 逐栋检索与层数依据

169 个建筑面中，19 条沿用 OSM 层数，6 条按照片中的窗排或外廊估读，144 条为俯视影像与建筑轮廓估值。逐面将原始 Overture 轮廓与卫星影像叠合，比较屋面、尺度和同类建筑。成组住宅参照底表有标注的六层住宅，教学楼参照同组的已知层数。部分新楼的底图仍是空地，部分极小或狭长的面难以辨认；这些估值只能用于控制模型体量。各条的 `floor_count_note` 说明依据。图书馆的立面存在悬挑和跨层窗，四层是估值。[Esri World Imagery](https://services.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer)

60 条具名非住宅记录中，22 条有地面外观照片。分母含四个车棚建筑面，南门与广场另计。检索使用“桂林电子科技大学 花江校区＋楼名”，在百度地图公开地点相册中核对楼号、铭牌、校区和照片主体；对信科楼同时使用中文楼号。外墙主色按实拍近似取值。[学校示意图](https://www.guet.edu.cn/hjxqdt/list.htm)

南门收录竖刻校名的立石；正德广场收录校方招聘活动报道中能看见铺地的一张。按“正德广场 孔子像”检索的图片还涉及其他学校、其他雕像，未能核实雕像细部。[正德广场现场报道](https://www.guet.edu.cn/2026/1108/c6356a162164/page.htm)
